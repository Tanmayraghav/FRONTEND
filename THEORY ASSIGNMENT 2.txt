Q1. What is the CSS Box Model?

The CSS Box Model describes how space is arranged around an HTML element. It has four parts:
1. Content – The actual text or image.
2. Padding – Space between content and border.
3. Border – Line around the padding and content.
4. Margin – Space outside the border.

Q2. What is a media query? Explain with sample code.

A media query is used to apply CSS according to screen size or device. It helps make a website responsive.

Example:
@media (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

This CSS changes the background color when the screen width is 600 pixels or less.

Q4. Write an example of a basic grid structure in Bootstrap.

Bootstrap uses containers, rows and columns to create a grid.

<div class="container">
  <div class="row">
    <div class="col">Column 1</div>
    <div class="col">Column 2</div>
    <div class="col">Column 3</div>
  </div>
</div>

Q5. What are CSS selectors?

CSS selectors are used to select HTML elements so that styles can be applied to them.

Examples:
1. Element selector: p { color: red; }
2. Class selector: .box { color: blue; }
3. ID selector: #main { color: green; }
4. Universal selector: * { margin: 0; }

Q6. What are CSS backgrounds? List their properties.

CSS background properties are used to set the background of an element.

Main properties:
1. background-color – Sets the background color.
2. background-image – Sets a background image.
3. background-repeat – Controls image repetition.
4. background-position – Sets the image position.
5. background-size – Sets the image size.
6. background-attachment – Controls whether the background scrolls.

Q7. How can we overlap elements in CSS?

We can overlap elements by using position and z-index. The z-index property controls which element appears in front.

Example:
.box1 {
  position: absolute;
  z-index: 1;
}
.box2 {
  position: absolute;
  z-index: 2;
}

Here, box2 appears in front of box1 if they overlap.

Q8. What are the different positioning properties in CSS?

1. static – Default position. The element follows normal page flow.
2. relative – Moves from its normal position.
3. absolute – Positioned relative to its nearest positioned parent.
4. fixed – Stays in the same place on the screen while scrolling.
5. sticky – Acts normally until a scroll point, then stays fixed within its container.

Q9. What is ECMAScript?

ECMAScript is the standard on which JavaScript is based. It defines JavaScript features and rules. New versions add features to the language.

Q10. Difference between var, let and const. Explain Temporal Dead Zone.

var:
- Function-scoped.
- Can be redeclared and updated.
- Can be used before its declaration, where its value is undefined.

let:
- Block-scoped.
- Can be updated but cannot be redeclared in the same scope.
- Cannot be used before its declaration.

const:
- Block-scoped.
- Cannot be reassigned or redeclared in the same scope.
- Must be given a value when declared.

Example:
var a = 10;
let b = 20;
const c = 30;

Temporal Dead Zone (TDZ): The time between entering a block and declaring a let or const variable is called the Temporal Dead Zone. During this time, the variable cannot be accessed.
